# N-KB — общая база знаний Lab и Project N

Каноническая версия: [docs/knowledge/INDEX.md в Lab main](https://github.com/Mefits/pixelfxGadot/blob/main/docs/knowledge/INDEX.md). Одна база для обоих проектов; не копировать её целиком в N. Она является документационным контуром, не зависимостью игры.

- [Combat Feel](https://github.com/Mefits/pixelfxGadot/blob/main/docs/knowledge/COMBAT_FEEL.md): hit-stop, управление, баланс.
- [Motion Stylization](https://github.com/Mefits/pixelfxGadot/blob/main/docs/knowledge/MOTION_STYLIZATION.md): выразительность и трейлы.
- [Visual QA](https://github.com/Mefits/pixelfxGadot/blob/main/docs/knowledge/VISUAL_QA.md): диагностика.
- [Determinism](https://github.com/Mefits/pixelfxGadot/blob/main/docs/knowledge/DETERMINISM.md): replay и PvP.
- [Workflow](https://github.com/Mefits/pixelfxGadot/blob/main/docs/knowledge/WORKFLOW.md): проверка и handoff.

Читайте индекс перед выбором решения; приоритет у явной задачи, текущей ветки и утверждённой архитектуры. Существующие [PLAN](PLAN.md) и [NETWORK_ARCHITECTURE](NETWORK_ARCHITECTURE.md) остаются обязательными. В обычном новом чате можно передать ссылку на индекс; автоматическое чтение внешнего репозитория не гарантируется.
