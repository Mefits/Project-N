# N — 0.07

Самостоятельный 2D-файтинг на Godot 4.4.1. Открой `project.godot`, нажми F5.

A/D — движение; W — прыжок; Shift — бег; F/H/J — быстрый/тяжёлый/удар ногой; T — дистанция удара; R — сброс; Space — пауза. F1 — скелет; F2 — второй игрок (стрелки, Ctrl, K/L/;); F3 — hitstop; F4 — гибридная реакция (по умолчанию включена); F5 — манекен; F6 — сравнение оболочек.

Далее: блокирование, контратаки, комбо, воздушный бой, оригинальный PixelFX и способности. Гибрид первого уровня сохранён, расширение отложено. Внешность временная.
