# N — 0.10.1

Самостоятельный 2D-файтинг на Godot 4.4.1. Открой `project.godot`, нажми F5.

A/D — движение; W — прыжок; Shift — бег; F/H/J — быстрый/тяжёлый/удар ногой; S — блок/парирование; Y — удар манекена; T — дистанция удара; R — сброс; Space — пауза. F1 — скелет; F2 — второй игрок (стрелки (вниз — блок), Ctrl, K/L/;); F3 — hitstop; F4 — гибридная реакция (по умолчанию включена); F5 — манекен; F6 — сравнение оболочек.

Базовая защита: удерживай S для блока, нажми S непосредственно перед контактом для парирования. После парирования отпусти S и атакуй. Далее: серии атак и переходы, подбрасывание и воздушный бой, оригинальный PixelFX и эксперимент с печатями. Гибрид первого уровня сохранён, расширение отложено. Внешность временная.

0.09a: F → F → F — первая серия руками. Следующее нажатие буферизуется во время удара, переход только после попадания. H/J остаются отдельными. Бег с более длинным шагом, ускорены одиночные атаки. Пока без четвёртого завершающего удара и воздушного боя. Тест: godot --headless --script res://tests/chain.gd

0.09b: F ×4 — серия с завершающим ударом ногой. Плавное сближение и торможение, разный отклик на попадания; фаза отрыва двух стоп при беге. Это ещё не воздушный бой. Третий удар теперь промежуточный, финальный отбрасывает сильнее.

0.09c: F → F → F → W+F (одновременно) — подбрасывание апперкотом; обычное F ×4 оставляет удар ногой. Второй игрок: K ×3, ↑+K. Подбрасывание только при контакте, с гравитацией и приземлением. Воздушные атаки пока не включены. Тест: godot --headless --script res://tests/launch.gd

0.10: T, F ×3 → W+F → после попадания отпусти F и нажми/удерживай W для преследования → F ×3 в воздухе. Последний удар направляет цель вниз. Вторая сторона: K, ↑+K, ↑, K. Обычный прыжок не даёт воздушной серии. Тест: godot --headless --script res://tests/air.gd

0.10.1: после финального воздушного удара атакующий резко возвращается вниз, цель падает на землю, лежит и поднимается. Пока лежит, не получает новые удары. Управление прежнее. Падение — авторская деформация скелета, не рэгдолл. Новые эффекты пока не добавлены.
